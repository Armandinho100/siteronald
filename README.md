# Império das Próteses — Landing page

Landing page responsiva em HTML, CSS e JavaScript, com direção visual **Luxo Cinematográfico**.

## Estrutura

- `index.html` — conteúdo e estrutura
- `styles.css` — identidade visual, layout e responsividade
- `script.js` — menu mobile, barra de progresso e animações
- `logoronald2.png` — **adicione aqui** a logo oficial
- `ronaldfoto.jpeg` — **adicione aqui** a foto pessoal do Ronald

## Como visualizar

1. Extraia a pasta.
2. Coloque `logoronald2.png` e `ronaldfoto.jpeg` na mesma pasta de `index.html`.
3. Abra `index.html` no navegador. Para publicar, envie os arquivos para o repositório GitHub/Vercel mantendo a estrutura.

## Imagens conceituais

As imagens externas do Unsplash são provisórias e meramente ilustrativas. Elas não representam trabalhos realizados pelo Império das Próteses. Substitua-as por fotos autorais e autorizadas do laboratório assim que estiverem disponíveis.

## Antes de publicar

Confirme com Ronald:
- Se o prazo de até 3 dias se aplica a todos os serviços; o site não anuncia esse prazo como garantia.
- Dias e horários de atendimento (a informação recebida sobre sexta e sábado ainda precisa ser esclarecida).
- Endereço completo, caso deseje exibi-lo.
- Se os serviços listados estão todos disponíveis atualmente.

O site usa links diretos para WhatsApp e Instagram. Não há formulário com armazenamento de dados nem envio de informações clínicas. A instalação e o planejamento clínico permanecem sob responsabilidade do dentista.

## Bibliotecas

GSAP e ScrollTrigger, Lenis e Google Fonts são carregados por CDN. O site mantém navegação e animações básicas mesmo se as bibliotecas de animação não carregarem.
